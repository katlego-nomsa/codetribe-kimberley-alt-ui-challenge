# La Maison - Modern Furniture Store
### CodeTribe Kimberley Alt UI Challenge

Live Demo: https://codetribe-kimberley-alt-ui-challeng-lemon.vercel.app/

## Project Overview
La Maison is a modern, elegant e-commerce UI for furniture and interior decor. Built as my MVP for the CodeTribe challenge, it focuses on clean aesthetics, responsive design, and user experience.

Inspired by the prompt: "An office that moves with you" - Transform your workspace into a haven of style and productivity.

## Tech Stack
- React + TypeScript
- Vite
- CSS
- Vercel for Deployment

## Features
- Navbar
- Hero Section with product showcase
- Feature Section
- Banner Section
- Footer

## Challenges Faced
- Fixed case-sensitivity issues for Vercel deployment (Windows vs Linux)
- Learned Vercel build configuration
